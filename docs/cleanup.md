# 費用と片付け

## 発生する可能性のある費用

| 項目 | 課金 |
| --- | --- |
| EC2 t3.medium | 起動中の計算料金 |
| EBS gp3（30GiB） | 停止中もストレージ料金 |
| パブリックIPv4 | 割り当て時間に応じた料金 |
| データ転送 | 条件と通信量に応じた料金 |

具体的な金額は[料金計算ツール](https://calculator.aws/)で東京リージョンを選択して確認してください。AWS Budgetsのアラートは**自動停止ではありません**。

## 練習を一時停止したい場合

EC2コンソールでインスタンスの「停止」を実行します。EBSの課金は続き、再起動後にパブリックIPv4が変わることがあります。再起動後はCloudFormationの出力値が古くなる場合があるため、EC2コンソール上の実際のIPを確認してください。

## 練習を終了して削除する場合（推奨）

1. [CloudFormationコンソール](https://console.aws.amazon.com/cloudformation/)を開く。
2. スタック `isucon13-practice` を選択し「削除」。
3. スタックが一覧から消えるか、削除完了を確認。
4. **EC2インスタンスとルートEBSボリュームが残っていないこと**をEC2コンソールで確認。
5. 不要なElastic IP・追加EBS・スナップショット等を自分で作っていた場合は別途確認。

削除するのはこのスタックで作ったEC2とセキュリティグループです。既存VPC/サブネットや自分で作成したSSHキーペアは削除されません。

> EC2の停止だけではディスク料金が止まりません。繰り返し最初から練習するならスタック削除→再作成が分かりやすい運用です。ただし変更したコードやデータは消えるため、必要なファイルは事前に安全な場所へ退避してください。
